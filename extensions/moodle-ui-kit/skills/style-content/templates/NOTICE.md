# Templates

These templates are adapted from [moodle-ui-kit](https://github.com/noeper/moodle-ui-kit), by [@noeper](https://github.com/noeper), released under CC0 1.0 Universal.

Changes: real headings (`<h2>`, `<h3>`) instead of bold paragraphs, labels as placeholders written in the course's language, a darker grey for the small captions, no font or background set over the course's theme (only the colored title bars and the code blocks keep theirs), decorative emojis hidden from screen readers with `aria-hidden="true"`, and `page.html`, a plain box for a page's or label's content, added.
